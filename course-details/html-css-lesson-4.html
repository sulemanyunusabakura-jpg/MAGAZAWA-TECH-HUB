HTML & CSS WEB DESIGN COURSE

Lesson 4: HTML Links and Navigation

Learn how to connect web pages together.

What Are HTML Links?

HTML links allow users to move from one web page to another.

Creating a Link

We use the HTML <a> element to create a link. 


<a href="about.html">
    About Us
</a>

Linking to Another Page

For example, if you have a page called contact.html, you can create a link to it like this: 


<a href="contact.html">
    Contact Us
</a>

Navigation Menu

A navigation menu is a group of links that helps visitors move around a website. 


<nav>

    <a href="index.html">Home</a>

    <a href="about.html">About</a>

    <a href="services.html">Services</a>

    <a href="contact.html">Contact</a>

</nav>

Practice Task

Create two HTML pages:

  • index.html
  • about.html

Then create a link on index.html that opens about.html.

Lesson 4 Complete

You now understand how HTML links work and how navigation menus connect different pages.
