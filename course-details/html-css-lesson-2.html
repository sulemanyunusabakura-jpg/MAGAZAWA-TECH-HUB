Lesson 2: Understanding HTML

Learn the basic structure of an HTML document.

What is HTML?

HTML means HyperText Markup Language. It is the main language used to create the structure of web pages.

Basic HTML Structure

A basic HTML page contains elements such as HTML, HEAD, TITLE and BODY.

Your First HTML Code 


<!DOCTYPE html>

<html>

<head>
    <title>My First Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is my first web page.
    </p>

</body>

</html>

Important HTML Elements

  • <h1> — Main heading
  • <p> — Paragraph
  • <a> — Link
  • <img> — Image
  • <button> — Button

Practice Task

Create a new HTML file called index.html.

Add a heading containing your name and a paragraph describing yourself.

Lesson 2 Complete

You now understand the basic structure of an HTML document.
