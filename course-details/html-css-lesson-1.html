Welcome to Lesson 1

Welcome to the HTML & CSS Web Design course at MAGAZAWA TECH HUB.

In this course, you will learn how to create websites step by step using HTML and CSS.

What is Web Design?

Web design is the process of creating and designing websites that people can access using a web browser.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure and content of a web page.

What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the appearance, colors, fonts, spacing and layout of a website.
