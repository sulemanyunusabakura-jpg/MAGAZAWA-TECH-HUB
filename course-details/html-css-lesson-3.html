HTML & CSS WEB DESIGN COURSE

Lesson 3: Creating Your First Web Page

Build your first simple HTML web page.

Your First Web Page

In this lesson, you will create a simple web page using HTML.

Step 1 — Create the File

Create a new file and name it: 

index.html

Step 2 — Add HTML Code 


<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <title>My First Website</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is my first website.
    </p>

</body>

</html>

Step 3 — Save the File

Save the file and open it with Google Chrome, Microsoft Edge, or another web browser.

What You Should See

  • A large heading saying "Welcome to My Website"
  • A paragraph underneath the heading
  • The page displayed inside your browser

Practice Task

Change the heading to your own name.

Then change the paragraph and write a short description about yourself.

Lesson 3 Complete

Congratulations! You have now created your first web page.
