Digital Watch

Arduino-based digital watch with temperature and humidity display.

Project Overview

The Digital Watch is an Arduino-based electronic system designed to display time together with environmental temperature and humidity information.

The system combines a real-time clock, environmental sensor, microcontroller and display unit to provide useful information to the user.

Aim of the Project

The aim of this project is to develop a digital watch using an Arduino microcontroller that can display accurate time together with temperature and humidity readings.

Objectives

  • Display the current time.
  • Measure environmental temperature.
  • Measure relative humidity.
  • Display sensor measurements.
  • Develop an Arduino-based embedded monitoring system.
  • Provide a simple and useful digital information display.

Main Components

  • Arduino Uno
  • Real-Time Clock (RTC) module
  • DHT11 temperature and humidity sensor
  • 16×2 LCD or OLED display
  • Resistors
  • Connecting wires
  • Power supply

Arduino Uno

The Arduino Uno acts as the main controller of the system.

It receives time information from the real-time clock and environmental measurements from the temperature and humidity sensor.

The Arduino processes this information and sends the results to the display.

Real-Time Clock

A real-time clock module can be used to maintain the current time and date.

The RTC communicates with the Arduino and provides information such as hours, minutes, seconds and date.

Using a dedicated RTC helps the system maintain time independently of the main program timing loop.

Temperature and Humidity Sensor

The DHT11 sensor can be used to measure environmental temperature and relative humidity.

The sensor sends its measurement data to the Arduino, which processes the readings and displays them to the user.

Display Unit

A display is used to present the system information in an easy-to-read format.

Depending on the selected display, the system can show:

  • Hours
  • Minutes
  • Seconds
  • Temperature
  • Humidity
  • Date

How the System Works

When the system is powered on, the Arduino initializes the connected modules.

The RTC provides the current time and date. At the same time, the environmental sensor provides temperature and humidity readings.

The Arduino processes the information and updates the display.

This process continues repeatedly while the system is operating.

Time Display

The display can show the current time in hours, minutes and seconds.

Example:

TIME: 10:45:32

Temperature Display

The measured environmental temperature can be displayed in degrees Celsius.

Example:

TEMP: 28°C

Humidity Display

The system can also display relative humidity as a percentage.

Example:

HUMIDITY: 65%

System Operation Sequence

  • Power on the system.
  • Initialize the Arduino.
  • Initialize the RTC.
  • Initialize the temperature and humidity sensor.
  • Read the current time.
  • Read temperature and humidity.
  • Update the display.
  • Repeat the monitoring process.

Applications

  • Home information displays
  • Classrooms
  • Laboratories
  • Offices
  • Weather monitoring demonstrations
  • Arduino educational projects

Advantages

  • Displays time and environmental information in one system.
  • Easy to understand.
  • Uses inexpensive electronic components.
  • Useful for Arduino learning.
  • Can be expanded with additional sensors.

Limitations

  • Sensor accuracy depends on the sensor used.
  • Some basic RTC modules may require periodic time adjustment.
  • LCD space limits the amount of information displayed at once.

Future Improvements

  • Add alarm functionality.
  • Add date and day display.
  • Add touchscreen control.
  • Add Wi-Fi connectivity.
  • Add mobile monitoring.
  • Add weather information.
