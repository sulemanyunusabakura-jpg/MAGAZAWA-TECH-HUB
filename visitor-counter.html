Digital Visitor Counter

8051 microcontroller-based visitor counting system with IR sensors and LCD.

Project Overview

The Digital Visitor Counter is an electronic system designed to automatically count people entering and leaving a room, office, laboratory or other controlled area.

The system uses an 8051 microcontroller, two infrared sensors and a 16×2 LCD display to detect movement and display the number of people currently inside the area.

Aim of the Project

The aim of this project is to design an automatic visitor counting system using an 8051 microcontroller, infrared sensors and an LCD display.

Objectives

  • Detect people entering an area.
  • Detect people leaving an area.
  • Automatically increase the visitor count when a person enters.
  • Automatically decrease the count when a person leaves.
  • Display the current number of people.
  • Develop a practical 8051-based embedded system.

Main Components

  • 8051 microcontroller
  • IR transmitter and receiver sensors
  • 16×2 LCD display
  • Crystal oscillator
  • Capacitors
  • Resistors
  • Power supply
  • Connecting wires

8051 Microcontroller

The 8051 microcontroller serves as the main controller of the visitor counting system.

It receives signals from the infrared sensors, processes the sensor sequence and updates the visitor count.

The calculated count is then sent to the LCD display.

IR Sensor System

Two infrared sensing points are used in the system.

One sensor is positioned to detect people entering the area, while the other sensor detects people leaving the area.

The controller interprets the sensor sequence to determine the direction of movement.

Entry Detection

When a person passes through the entrance, the entry sensor detects the movement.

The 8051 processes the sensor signal and increases the visitor count by one.

For example:

Previous Count: 5

New Count: 6

Exit Detection

When a person leaves the monitored area, the exit sensor detects the movement.

The 8051 processes the signal and decreases the visitor count by one.

The system should prevent the count from becoming negative.

For example:

Previous Count: 6

New Count: 5

Counting Logic

The basic counting logic is:

  • Detect entry sensor activation.
  • Confirm the movement sequence.
  • Increase the count.
  • Detect exit sensor activation.
  • Confirm the exit movement sequence.
  • Decrease the count.
  • Update the LCD display.

LCD Display

The 16×2 LCD displays the number of people currently detected inside the monitored area.

Example display:

PEOPLE INSIDE

COUNT: 12

System Operation

When the system is powered on, the 8051 initializes the LCD and sensor inputs.

The controller continuously monitors both infrared sensors.

When a valid entry sequence is detected, the count increases.

When a valid exit sequence is detected, the count decreases.

The LCD is updated whenever the count changes.

System Structure

The major parts of the system are connected in the following logical arrangement:

  • Entry IR Sensor → 8051
  • Exit IR Sensor → 8051
  • 8051 → 16×2 LCD
  • Power Supply → System Components

Applications

  • Offices
  • Classrooms
  • Laboratories
  • Libraries
  • Meeting rooms
  • Exhibition halls
  • Shopping environments

Advantages

  • Automatic visitor counting.
  • Reduces manual counting.
  • Provides real-time count information.
  • Simple electronic architecture.
  • Useful for embedded-system education.

Limitations

  • Sensor alignment can affect detection.
  • Multiple people passing simultaneously may require improved detection logic.
  • Strong environmental interference can affect some IR sensors.
  • The system requires suitable placement of the two sensing points.

Future Improvements

  • Add a larger display.
  • Add cloud-based monitoring.
  • Improve multiple-person detection.
