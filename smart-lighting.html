Smart Lighting System

Arduino-based lighting system with motion and voice control.

Project Overview

The Smart Lighting System is an Arduino-based project designed to control electrical lighting automatically using motion detection and voice commands.

The system combines a microcontroller, motion sensor, relay module and lighting load to provide convenient and intelligent lighting control.

A voice-control interface can also be incorporated to allow the user to switch the light ON or OFF using voice commands.

Aim of the Project

The aim of this project is to develop a smart lighting system capable of controlling lights automatically through motion detection and manually through voice commands.

Objectives

  • Detect movement within a monitored area.
  • Automatically control lighting.
  • Provide voice-based lighting control.
  • Reduce unnecessary energy consumption.
  • Provide convenient lighting control.
  • Demonstrate the application of microcontrollers in smart homes.

Main Components

  • Arduino Uno
  • PIR motion sensor
  • Relay module
  • LED or suitable lighting load
  • Voice-control module or interface
  • Resistors
  • Connecting wires
  • Power supply

Arduino Uno

The Arduino Uno serves as the main controller of the smart lighting system.

It receives information from the motion sensor and voice-control interface and processes the information according to the programmed control logic.

The Arduino then controls the relay to switch the lighting load ON or OFF.

PIR Motion Sensor

A PIR sensor is used to detect movement caused by people within its sensing area.

When motion is detected, the sensor sends a signal to the Arduino.

The Arduino can then activate the light through the relay module.

Relay Module

The relay module acts as an electrically controlled switch between the Arduino and the lighting load.

It allows the low-voltage control system to control an appropriate electrical load.

For practical mains-voltage installations, suitable electrical protection, insulation and qualified installation practices must be used.

Lighting Load

An LED lamp or another suitable lighting load can be controlled by the relay.

When the relay is activated, the lighting load turns ON. When the relay is deactivated, the lighting load turns OFF.

Voice Control

Voice control allows the user to operate the lighting system using predefined voice commands.

Example commands may include:

  • Turn light on
  • Turn light off
  • Switch light on
  • Switch light off

The exact voice-control method depends on the hardware or software interface used in the final implementation.

Motion Control

When the PIR sensor detects movement, the Arduino receives a HIGH signal.

The Arduino can then activate the relay, causing the connected light to turn ON.

After the programmed delay period, the Arduino can switch the light OFF if no further motion is detected.

How the System Works

When the system is powered on, the Arduino initializes the motion sensor, relay and voice-control interface.

The Arduino continuously monitors the motion sensor and waits for a valid voice command.

If motion is detected, the Arduino activates the relay and switches the light ON according to the programmed logic.

If the user provides a valid voice command, the Arduino can also switch the light ON or OFF.

The system therefore provides both automatic motion-based control and user-controlled operation.

System Operation Sequence

  • Switch on the system.
  • Arduino initializes the components.
  • PIR sensor monitors the environment.
  • User can issue a voice command.
  • Arduino processes the received input.
  • Relay is activated when the light should turn ON.
  • Relay is deactivated when the light should turn OFF.
  • System continues monitoring.

Example of Operation

Assume a person enters a room where the smart lighting system is installed.

The PIR sensor detects the person's movement and sends a signal to the Arduino.

The Arduino processes the signal and activates the relay.

The light then turns ON automatically.

Alternatively, the user can issue a supported voice command to control the light.

Applications

Advantages

  • Provides automatic lighting control.
  • Provides convenient voice control.

Limitations

  • PIR sensors have a limited detection range.
  • Voice control depends on the selected voice-control interface.
  • False motion detections may occasionally occur.
  • The system requires a suitable power supply.
