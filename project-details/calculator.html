Arduino Calculator

A simple electronic calculator system developed using an Arduino microcontroller.

Project Overview

The Arduino Calculator is a simple microcontroller-based electronic system designed to perform basic mathematical operations.

The system uses an Arduino microcontroller, keypad and display to allow a user to enter numbers and mathematical operators.

The Arduino processes the user's input, performs the selected mathematical operation and displays the result.

Aim of the Project

The aim of this project is to design an Arduino-based calculator capable of performing basic mathematical operations and displaying the results to the user.

Objectives

  • Accept numerical input from a keypad.
  • Detect mathematical operators.
  • Perform basic arithmetic operations.
  • Display the entered values and results.
  • Provide a simple and user-friendly calculator interface.
  • Demonstrate the use of Arduino in practical electronic applications.

Main Components

  • Arduino Uno
  • 4×4 or suitable matrix keypad
  • 16×2 LCD display
  • 10kΩ potentiometer for LCD contrast
  • Connecting wires
  • Resistors where required
  • Suitable power supply

Arduino Uno

The Arduino Uno serves as the main controller of the calculator.

It receives input from the keypad, identifies the numbers and mathematical operators, performs the required calculation and sends the result to the LCD display.

Keypad

The keypad provides the interface through which the user enters numbers and commands.

A typical keypad may contain numerical keys together with mathematical operators.

Example keys include:

  • 0 to 9
  • Addition (+)
  • Subtraction (-)
  • Multiplication (*)
  • Division (/)
  • Clear (C)
  • Equals (=)

16×2 LCD Display

The LCD display provides visual feedback to the user.

It can display the numbers entered, mathematical operators and calculated results.

For example, the display may show:

25 + 15 = 40

LCD Contrast Control

A 10kΩ potentiometer can be used to adjust the contrast of the 16×2 LCD display.

Adjusting the potentiometer makes the characters on the LCD easier to see.

Mathematical Operations

The calculator can be programmed to perform several basic mathematical operations.

  • Addition
  • Subtraction
  • Multiplication
  • Division

Example:

  • 10 + 5 = 15
  • 20 - 8 = 12
  • 6 × 4 = 24
  • 20 ÷ 5 = 4

Working Principle

When the calculator is powered on, the Arduino initializes the keypad and LCD.

The user enters a number using the keypad. The Arduino detects each key press and stores the corresponding value.

The user then enters a mathematical operator followed by the second number.

When the equals key is pressed, the Arduino performs the selected operation.

The calculated result is then displayed on the LCD.

System Operation Sequence

  • Switch on the calculator.
  • Arduino initializes the system.
  • LCD displays the initial message.
  • User enters the first number.
  • User selects an arithmetic operator.
  • User enters the second number.
  • User presses the equals key.
  • Arduino performs the calculation.
  • Result is displayed on the LCD.
  • User can clear the display and perform another calculation.

Example of Operation

Suppose the user wants to calculate:

25 + 15

The user enters 25 using the keypad, selects the addition operator (+), and then enters 15.

After pressing the equals (=) key, the Arduino calculates the result.

The LCD displays:

25 + 15 = 40

Error Handling

The calculator can be programmed to identify invalid operations.

One important example is division by zero.

If the user attempts to divide a number by zero, the system should display an appropriate error message instead of producing an invalid result.

Example:

Error: Cannot divide by zero
