Lithium-Ion Battery Charger & Monitor

A microcontroller-based automatic charging system with real-time voltage monitoring and auto-cut-off protection to prevent overcharging.

🛠️ Required Components

  • Arduino Uno / ATmega328P Microcontroller
  • TP4056 Lithium Battery Charging Module
  • 0.96" I2C OLED Display
  • 5V Relay Module (Auto-Cut-Off switch)
  • Voltage Divider Resistors & Current Sensor

📌 Key Features

  • Real-time battery voltage monitoring
  • Automatic relay cut-off at 4.2V
  • Visual status indicator on OLED screen
