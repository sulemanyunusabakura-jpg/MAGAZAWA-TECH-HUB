Smart Microcontroller Load Switcher

An automated microcontroller load management and environmental monitoring system built to safely control high-power electrical equipment via sensor thresholds.

🛠️ Required Components

  • ATmega328P / PIC / ESP Microcontroller
  • Optocoupler Isolated Relay Module
  • DHT11 / DHT22 Temperature & Humidity Sensor
  • 16x2 I2C Character LCD
  • 5V Regulated Power Supply Circuit

📌 Key Features

  • Automated relay switching based on temperature thresholds
  • Optocoupler isolation for microcontroller protection
  • EEPROM state memory to restore settings after power outages
