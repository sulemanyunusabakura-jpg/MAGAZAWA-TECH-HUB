Automatic Rice Cooker

Microcontroller-based automatic cooking and temperature control system.

Project Overview

The Automatic Rice Cooker is a microcontroller-based system designed to control the cooking process using temperature monitoring and automatic switching.

An Arduino Uno receives temperature information from a sensor and controls the cooking system through an appropriate switching device.

A display can also be used to provide information about the operating status of the cooker.

Aim of the Project

The aim of this project is to develop an automatic rice cooking control system capable of monitoring temperature and automatically controlling the cooking and warming processes.

Objectives

  • Monitor cooking temperature.
  • Automatically control the cooking process.
  • Provide a warming mode after cooking.
  • Display the operating status.
  • Reduce unnecessary continuous heating.
  • Develop a practical Arduino-based control system.

Main Components

  • Arduino Uno
  • LM35 temperature sensor
  • 16×2 LCD display
  • Relay module or suitable solid-state switching device
  • Cooking heating element
  • LEDs for status indication
  • Resistors
  • Connecting wires
  • Suitable power supply

Temperature Monitoring

The LM35 temperature sensor can be used to measure temperature and provide an analog voltage to the Arduino.

The Arduino reads the sensor signal and converts the measurement into a temperature value that can be used by the control program.

The sensor allows the controller to determine when the cooking process has reached the programmed condition.

How the System Works

When the cooker is switched on, the Arduino begins monitoring the temperature sensor.

During the cooking stage, the controller activates the heating system through an appropriate switching device.

The temperature is continuously monitored. When the programmed cooking condition is reached, the controller changes the operating state.

The system can then enter a warming mode rather than continuing the main cooking heating cycle.

Cooking Mode

During cooking mode, the heating element is controlled according to the temperature and control conditions programmed into the Arduino.

A red LED can be used to indicate that the cooker is currently in cooking mode.

Warming Mode

After the cooking stage, the system can enter a warming state.

A green LED can be used to indicate the warming condition.

The exact temperature thresholds and switching behavior should be selected according to the actual cooker design, heating element and safety requirements.

LCD Display

A 16×2 LCD can be used to display useful information to the user.

  • Current temperature
  • Cooking status
  • Warming status
  • System messages

For example, the display could show:

Temperature: 85°C

followed by a status such as:

Cooking...

Heating Control

The Arduino should not directly power a high-power heating element.

Instead, an appropriately rated switching device and properly designed electrical isolation and protection should be used.

For an academic prototype, the control concept can be demonstrated using a relay module, while real mains-voltage construction requires qualified electrical design and appropriate safety measures.

Control Logic

The basic control sequence can be represented as follows:

  • Start system.
  • Read temperature.
  • Activate cooking control.
  • Continue monitoring temperature.
  • Change to warming condition when the programmed condition is reached.
  • Display the current operating status.
